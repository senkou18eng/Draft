# Draft（送信前の下書きアプリ）

送る前にここで書き、待ち時間と確認を通してからコピーするための、単一ページのPWAです。
サーバー側の処理はなく、下書きはこの端末のブラウザ内（localStorage）にだけ保存されます。

## ファイル

| ファイル | 役割 |
|---|---|
| index.html | アプリ本体（HTML・CSS・JavaScriptを1ファイルに収めています） |
| manifest.webmanifest | ホーム画面に追加したときの名前・アイコン・表示方法 |
| sw.js | オフラインでも開けるようにするservice worker |
| icon-180.png / icon-512.png | アイコン |

## 公開の手順（GitHub Pagesの例）

service workerはHTTPSでしか動かないため、HTTPSで配信できる場所に置く必要があります。

1. GitHubで新しいリポジトリを作り、このフォルダの中身をそのままアップロードする。
2. リポジトリの Settings → Pages で、公開元にそのブランチのルートを選ぶ。
3. 表示されたURL（https://ユーザー名.github.io/リポジトリ名/）を開いて動作を確認する。

Cloudflare PagesやNetlifyなど、静的ファイルをHTTPSで配信できる場所ならどこでも同じです。
パスはすべて相対指定なので、サブディレクトリに置いても動きます。

## iPhoneへの入れ方

1. 公開したURLをSafariで開く。
2. 共有ボタン →「ホーム画面に追加」。
3. ホーム画面のアイコンから開く（アドレスバーのない単独の画面で開きます）。

## 使い方

1. 下書きを書く。
2. 待ち時間（すぐ／10分／翌朝7時）を選び、「この内容で待つ」を押す。押したあとは短くできません。
3. 待ち時間が終わったら読み返し、確認にチェックを入れる。
4. 「コピーする」→「Discordを開く」→ 貼り付けて送る。

待つあいだに返事が必要なときは、「つなぎの一言」をそのままコピーして送れます。

## 知っておくこと

- 待ち時間が終わっても通知は出ません。自分で開き直す必要があります。
- 待ち時間の途中で文面を書き換えても、待ち時間はやり直しになりません。
- 「翌朝7時」は、次の7:00までが5時間未満のときは、その次の日の7:00になります。
- 保存先はブラウザの保存領域です。サイトデータを消すと下書きも消えます。
  Safariで開いたときと、ホーム画面のアイコンから開いたときでは、保存領域が別になることがあります。

## 変更したいとき（すべて index.html の中）

- 原則の文言：`<section class="rules">` の中。
- つなぎの一言：`data-hold="…"` の付いたボタン。属性の値とボタンの文字を両方変える。
- 待ち時間の長さ：`lockTime` 関数（10分）と `nextMorning` 関数（7時、5時間）。
- 開くアプリ：`<a class="btn" id="open" href="discord://">`。

ファイルを更新したら、`sw.js` の `CACHE` の番号を上げてください。上げないと、端末に古い版が残ります。
